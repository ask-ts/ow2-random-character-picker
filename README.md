# ow2-random-character-picker

## 概要
OW2のキャラクターをランダムにピックするアプリです。

## デモ
[OW2ランダムキャラピッカー](https://ow2-random-character-picker.vercel.app/)

## 主な機能
- ロール（タンク/ダメージ/サポート）を選択してランダムにキャラをピック
- 全キャラクターの中からランダムにピック
- 履歴を10回まで保存、表示

## 使用技術
- HTML/CSS
- JavaScript
- BootStrap
